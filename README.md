# Adaptive MoE Project Report

Private collaboration repository for the Research Project report.

## Files

- `project_report.tex` — report source.
- `references.bib` — citations used by the report.

## Build

Install Tectonic, then run:

```sh
tectonic project_report.tex
```

The report is a draft. Review the institute-specific certificate wording, signatures, acknowledgements, and any remaining submission requirements before final submission.
